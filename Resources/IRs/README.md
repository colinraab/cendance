## Processing

Freesound requires an account to download the original WAV files. These bundled
files were created from Freesound's publicly available high-quality OGG previews,
then decoded and standardized to 48 kHz, 16-bit PCM WAV. No additional EQ,
normalization, trimming, or dynamics processing was applied.

The responses range from 0.71 to 7.51 seconds and include mono and stereo
captures. They are embedded into the cendance executable at build time, so a
preset does not depend on the current working directory or an external resource
folder.
