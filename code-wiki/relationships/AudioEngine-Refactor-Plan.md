# AudioEngine.cpp Refactor Plan

> Generated by Codex on 2026-05-14. See `.hermes/plans/audioengine-refactor.md` for full details.

## Summary

Split `AudioEngine.cpp` (2,836 lines) into two new files:

| New File | Lines Moved | Content |
|----------|-------------|---------|
| `EffectProcessor.cpp/.h` | ~1,350 | All effect configuration, processing, preset application, spot effects, composite presets. Owns 40+ effect member arrays. |
| `CommandProcessor.cpp/.h` | ~650 | Command dispatch (`processCommands()`), custom algorithm runtime storage, algorithm ID helpers. Uses Delegate pattern for engine callbacks. |
| `AudioEngine.cpp` (remaining) | ~836 | Constructor/destructor, audio callback, transport, arrangement, spectrum, metronome, algorithm map init, sound/drum presets. |

## Architecture

```
AudioEngine
├── EffectProcessor effectProcessor    // owns all effect arrays + processing
├── CommandProcessor commandProcessor  // owns command dispatch + custom algorithms
│   └── Delegate (abstract interface)  // callbacks into AudioEngine for:
│       ├── applySoundPreset()
│       ├── resetTransportAndArrangement()
│       ├── resetAlgorithm()
│       └── drum sample setters
├── Transport transport
├── DrumEngine, BassEngine, ChordEngine, LeadEngine
└── built-in algorithm instances
```

## Key Design Decisions

1. **EffectProcessor owns effect arrays** — reduces AudioEngine.h from 414 to ~200 lines of includes
2. **CommandProcessor uses Delegate pattern** — abstract base class with virtual calls, no std::function on audio path
3. **Custom algorithm storage moves to CommandProcessor** — getMaxAlgorithmIdForTrack/getTrackAlgorithm forwarded from AudioEngine
4. **Public API unchanged** — same constructor signature, same public methods
5. **Real-time safety preserved** — no new allocations or locks on audio path

## Files to Create

1. `Source/Audio/EffectProcessor.h` — class declaration + all effect member arrays
2. `Source/Audio/EffectProcessor.cpp` — effect config/processing (~1,350 lines moved)
3. `Source/Audio/CommandProcessor.h` — class declaration + Delegate interface
4. `Source/Audio/CommandProcessor.cpp` — command dispatch + custom algorithm storage (~650 lines moved)
